# RocketUp

A native macOS 27 app launcher. It runs without a Dock icon and shows a menu bar icon by default. Press ⌘\ to open it; use ⌘, in the launcher or the menu bar menu to change the shortcut, toggle the menu bar icon, or enable launch at login. If a shortcut is assigned to macOS, release it in System Settings before assigning it here. Quit using Force Quit.

Searches app bundles in `/Applications`, `/System/Applications`, `/System/Library/CoreServices/Applications`, and `~/Applications`, including subfolders. The sandbox uses a read-only home-relative temporary exception for `~/Applications`. Search ranks exact names, full-name prefixes, later word prefixes, then initials; space and punctuation insensitive matching is a fallback. Changes are observed with filesystem events. Everything stays local.

Type a calculation such as `100 / 42`, `(2 + 3) * 4`, `sin(pi / 2)`, or `sqrt(81)` to see its result. Return (or clicking the result) copies the displayed number to the clipboard and closes the launcher. Functions include `sin`, `cos`, `tan`, inverse trig functions, `sqrt`, `pow`, `abs`, `floor`, `ceil`, `round`, `min`, `max`, `mod`, `exp`, `log`/`ln` (natural log), `log10`, and `log2`; constants include `pi`/`π`, `e`, and `tau`. Trig uses radians, powers use `pow(base, exponent)`, and multiplication must be explicit. Decimal points and scientific notation work; `×`, `÷`, and `−` are accepted too. Results use floating-point arithmetic with 15 significant digits; displayed and copied numbers follow the current macOS locale’s decimal separator. Expressions use decimal points and commas between function arguments. Incomplete, invalid, or non-finite calculations fall back to app search. Input is limited to 512 UTF-8 bytes and 32 nested parentheses.

The numeric evaluator is an unmodified, vendored copy of Expression 0.13.9 locked to an exact commit and SHA-256 checksums. Its MIT license ships in the app's resources. See the [dependency inspection](docs/expression-audit.md) and [lock file](docs/Expression.lock.json). `./scripts/test-calculator.sh` checks the dependency hashes and calculator behavior.

Build a signed local app with `./scripts/build-app.sh`, or open `RocketUp.xcodeproj` in Xcode. The project uses the Taglab team, the `com.taglab.rocketup` identifier, and the App Sandbox. `./scripts/test-search.sh` checks matching; `./scripts/test-integration.sh` checks discovery and notifications inside a development-signed sandbox and briefly displays the launcher. Set `ROCKETUP_CHECK_LAUNCH=1` on that test to check launching Calculator. The latter closes Calculator afterward only if it was not already running.

For App Store releases, `./scripts/build-app-store.sh` archives and exports with automatic signing; `--upload` uploads the archive. Xcode Cloud runs search and versioning checks and archives tagged releases; see [Xcode Cloud releases](docs/xcode-cloud.md). The App Store Connect listing still needs configuration. The read-only home-relative temporary exception must be explained in App Store Connect, including a Feedback Assistant issue number, and its acceptance is subject to App Review.

The results panel resizes over 200 ms; search computation alone has been measured in the integration test. Display selection currently uses AppKit's main screen and has not been verified against Spotlight on multiple monitors.
